bevy_soundfont_synth demo

Plays immediate MIDI events, a timed event sequence, and MIDI file playback through a firewheel + rustysynth audio graph. Logs go to the browser console (F12).

WebAudio needs a user gesture — nothing plays until you interact.

“Only Time.mid” from the Lakh MIDI Dataset (CC-BY 4.0) — see Only Time.mid.license.
